# Printed Parts (CAD) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every printed part of the gnome as files the slicer can take — STEP and STL for the mechanism, STL for the sculpted shell — generated from one parameters module, checked by tests, and previewed by renders.

**Architecture:** `cad/params.py` holds every dimension. `cad/mech/*.py` builds the mechanism in build123d and exports STEP + STL. `cad/shell/*.py` sculpts the raw shell sections in Blender (headless) and exports closed meshes. `cad/assemble.py` unions the build123d interface parts into the raw sections and cuts the openings and splits with manifold3d, writing the printable sections. `cad/build.py` runs the stages in order. Tests check validity, size, fit and clearance without a printer; previews are the look test.

**Tech Stack:** Python 3.11 in `.venv-cad` (build123d 0.13, bd_warehouse, trimesh, manifold3d, rtree, numpy, pytest), Blender 5.2 LTS at `/Applications/Blender.app` with its bundled Python.

**Spec:** `docs/superpowers/specs/2026-09-22-cad-parts-design.md`. Read it first; the numbers below come from it and from three probes run while planning: build123d exports a valid STEP on this Mac, Blender's own exact boolean leaves non-manifold meshes on subdivided input while manifold3d does not, and a voxel-remeshed, solidified Blender mesh survives manifold unions and cuts watertight.

**Coordinate system, everywhere:** millimetres, Z up, +X is the direction the gnome faces, origin at the centre of the floor.

**Conventions:**
- Commit after every task with the repository's usual style (a subject line, a body that says why, and the attribution trailer the session's system reminder specifies).
- `cad/out/` is ignored by git. Never commit generated STEP, STL or PNG.
- Run tests with `.venv-cad/bin/pytest cad/tests -q` from the repository root.
- Blender is `/Applications/Blender.app/Contents/MacOS/Blender`; `build.py` reads `BLENDER` from the environment to override it.

```python
def shell_r(profile, z):
    """Outer radius of a revolved profile at height z, linear between points."""
    pts = sorted(profile, key=lambda p: p[1])
    if z <= pts[0][1]:
        return pts[0][0]
    for (r0, z0), (r1, z1) in zip(pts, pts[1:]):
        if z0 <= z <= z1:
            if z1 == z0:
                return max(r0, r1)
            return r0 + (r1 - r0) * (z - z0) / (z1 - z0)
    return pts[-1][0]
```

```python
"""The mechanism. `ALL` is filled in by the part modules as they are written."""
ALL = []          # (name, builder) in build order
INTERFACES = {}   # shell section -> [part names unioned into it]


def part(name, section=None):
    """Register a builder. Interface parts also name the shell section they join."""
    def wrap(fn):
        ALL.append((name, fn))
        if section:
            INTERFACES.setdefault(section, []).append(name)
        return fn
    return wrap
```

```python
from pathlib import Path
from build123d import (Box, Cylinder, Pos, Rot, Part, export_step, export_stl, Align)
import params as P

OUT = Path(__file__).resolve().parents[1] / "out"
STEP = OUT / "step"
STL = OUT / "stl"


def export(part: Part, name: str) -> None:
    STEP.mkdir(parents=True, exist_ok=True)
    STL.mkdir(parents=True, exist_ok=True)
    export_step(part, str(STEP / f"{name}.step"))
    export_stl(part, str(STL / f"{name}.stl"), tolerance=0.05, angular_tolerance=0.1)


def cyl_z(r, z0, z1, x=0.0, y=0.0):
    """A cylinder along Z from z0 to z1."""
    return Pos(x, y, (z0 + z1) / 2) * Cylinder(r, z1 - z0)


def cyl_y(r, y0, y1, x=0.0, z=0.0):
    return Pos(x, (y0 + y1) / 2, z) * Rot(90, 0, 0) * Cylinder(r, y1 - y0)


def cyl_x(r, x0, x1, y=0.0, z=0.0):
    return Pos((x0 + x1) / 2, y, z) * Rot(0, 90, 0) * Cylinder(r, x1 - x0)


def box(x0, x1, y0, y1, z0, z1):
    return Pos((x0 + x1) / 2, (y0 + y1) / 2, (z0 + z1) / 2) * Box(x1 - x0, y1 - y0, z1 - z0)


def servo_body(spec, shaft_xyz, axis="z", length_dir=(0, -1, 0)):
    """A servo as a solid, for clearance checks and cutters.

    `shaft_xyz` is where the output shaft leaves the body; `axis` is the shaft direction;
    `length_dir` is the direction the body's length runs away from the shaft end. Only the
    two orientations this design uses are supported: shaft up with the length along -Y
    (pan), and shaft along +Y with the length along -Z (tilt).
    """
    L, W, H = spec["body"]
    off = spec["shaft_off"]
    sx, sy, sz = shaft_xyz
    if axis == "z":
        # length along -Y: body spans y in [sy - (L - off), sy + off]
        return box(sx - W / 2, sx + W / 2, sy - (L - off), sy + off, sz - H, sz)
    if axis == "y":
        # shaft along +Y, length along -Z: body spans z in [sz - (L - off), sz + off]
        return box(sx - W / 2, sx + W / 2, sy - H, sy, sz - (L - off), sz + off)
    raise ValueError(axis)


def phone_body():
    """The iPhone standing upright, camera end down, screen facing -X, camera on the centreline."""
    return box(P.PHONE_FRONT_X, P.PHONE_BACK_X,
               -P.PHONE_Y_OFFSET - P.PHONE_W / 2, -P.PHONE_Y_OFFSET + P.PHONE_W / 2,
               P.PHONE_BOTTOM_Z, P.PHONE_BOTTOM_Z + P.PHONE_L)


def canister_body():
    L, W, H = P.CANISTER
    cx, cy = P.CANISTER_XY
    return box(cx - L / 2, cx + L / 2, cy - W / 2, cy + W / 2, P.Z_FLOOR + 6, P.Z_FLOOR + 6 + H)


def pump_body():
    L, W, H = P.PUMP
    cx, cy = P.PUMP_XY
    return box(cx - L / 2, cx + L / 2, cy - W / 2, cy + W / 2, P.Z_FLOOR + 10, P.Z_FLOOR + 10 + H)


def insert_holes(part, points, depth=P.INSERT_DEPTH, r=P.INSERT_D / 2, direction="down"):
    """Blind holes for heat-set inserts, drilled from each (x, y, z) point."""
    for x, y, z in points:
        if direction == "down":
            part = part - cyl_z(r, z - depth, z + 0.01, x, y)
        elif direction == "up":
            part = part - cyl_z(r, z - 0.01, z + depth, x, y)
    return part
```

```python
#!/usr/bin/env python
"""Build the printed parts. Stages: mech, shell, assemble, preview. No argument runs all."""
import os
import subprocess
import sys
from pathlib import Path

CAD = Path(__file__).resolve().parent
sys.path.insert(0, str(CAD))
BLENDER = os.environ.get("BLENDER", "/Applications/Blender.app/Contents/MacOS/Blender")


def mech():
    import mech  # noqa: F401  (registers builders)
    import mech.turntable, mech.torso, mech.head, mech.base  # noqa: E401,F401
    from mech.common import export
    from mech import ALL
    for name, builder in ALL:
        print(f"mech  {name}")
        export(builder(), name)


def blender(script):
    subprocess.run([BLENDER, "-b", "--python", str(CAD / "shell" / script)], check=True)


def shell():
    for script in ("body.py", "head.py", "beard.py"):
        print(f"shell {script}")
        blender(script)


def assemble():
    import assemble as a
    a.main()


def preview():
    blender("preview.py")


STAGES = {"mech": mech, "shell": shell, "assemble": assemble, "preview": preview}

if __name__ == "__main__":
    names = sys.argv[1:] or list(STAGES)
    for n in names:
        STAGES[n]()
```

```python
import math
from build123d import Cylinder, Box, Pos, Rot, RegularPolygon, extrude, Plane, Axis
import params as P
from mech import part
from mech.common import cyl_z, cyl_y, box, insert_holes, servo_body


def _polar(r, deg, z):
    return (r * math.cos(math.radians(deg)), r * math.sin(math.radians(deg)), z)


def _notch(z0, z1):
    (x0, y0), (x1, y1) = P.PAN_NOTCH
    return box(x0, x1, y0, y1, z0, z1)


def _servo_tab_holes():
    L, W, H = P.DS3218["body"]
    along, across = P.DS3218["holes"]
    sx, sy = P.PAN_SERVO_XY
    cy = sy - (L - P.DS3218["shaft_off"]) / 2 + P.DS3218["shaft_off"] / 2  # body centre along Y
    cy = sy + P.DS3218["shaft_off"] - L / 2
    return [(sx + dx, cy + dy) for dx in (-across / 2, across / 2) for dy in (-along / 2, along / 2)]


@part("deck_ring", section="torso")
def deck_ring():
    """Ledge inside the shoulders that the deck bolts to. Unioned into the torso."""
    z1 = P.Z_DECK - P.DECK_T
    z0 = z1 - P.RING_T
    r_out = P.ring_r_out(P.TORSO_PROFILE, z0)
    ring = cyl_z(r_out, z0, z1) - cyl_z(P.RING_R_IN, z0 - 1, z1 + 1)
    # the pan servo hangs through here with its tabs on the deck; clear the whole tab footprint
    (x0, y0), (x1, y1) = P.PAN_NOTCH
    tab = P.DS3218["tab_span"]
    ring = ring - box(x0 - 1, x1 + 1, y0 - (tab - P.DS3218["body"][0]) / 2 - 8, y1 + (tab - P.DS3218["body"][0]) / 2 + 8, z0 - 1, z1 + 1)
    ring = insert_holes(ring, [_polar(P.DECK_SCREW_R, a, z1) for a in P.DECK_SCREW_ANGLES], depth=P.RING_T - 1)
    return ring


@part("deck")
def deck():
    """Carries the bearing's fixed ring, the pan servo and the pan hard stops."""
    z1, z0 = P.Z_DECK, P.Z_DECK - P.DECK_T
    d = cyl_z(P.DECK_R, z0, z1)
    d = d - cyl_z(P.SHAFT_OD / 2 + P.CLEAR + 1.0, z0 - 1, z1 + 1)          # shaft passes with room
    for a in (45, 135, 225, 315):                                          # bearing screws
        x, y, _ = _polar(P.BEARING_PITCH / 2 * math.sqrt(2), a, 0)
        d = d - cyl_z(P.BEARING_HOLE / 2, z0 - 1, z1 + 1, x, y)
    for a in P.DECK_SCREW_ANGLES:                                          # down into the ring
        x, y, _ = _polar(P.DECK_SCREW_R, a, 0)
        d = d - cyl_z(P.M3_CLEAR / 2, z0 - 1, z1 + 1, x, y)
    d = d - _notch(z0 - 1, z1 + 1)                                         # pan servo body
    for x, y in _servo_tab_holes():                                        # tab screws, nut below
        d = d - cyl_z(P.M3_CLEAR / 2, z0 - 1, z1 + 1, x, y)
        d = d - Pos(x, y, z0 + P.NUT_M3_T / 2 - 0.01) * extrude(RegularPolygon(P.NUT_M3_AF / math.sqrt(3), 6), P.NUT_M3_T)
    # hard-stop posts either side of the plate's front tab
    half_tab = math.degrees(math.atan2(P.STOP_TAB_W / 2, P.PLATE_R))
    for sign in (1, -1):
        x, y, _ = _polar(P.STOP_POST_R, sign * (P.PAN_STOP_DEG + half_tab + math.degrees(math.atan2(P.STOP_POST_D / 2, P.STOP_POST_R))), 0)

    z1 = P.Z_PLATE_TOP

    p = p - cyl_z(P.SHAFT_OD / 2 + 0.1, z0 - 1, z1 + 1)                    # shaft bonds in here

        x, y, _ = _polar(P.BEARING_PITCH / 2 * math.sqrt(2), a, 0)
        p = p - cyl_z(P.BEARING_HOLE / 2, z0 - 1, z1 + 1, x, y)
    p = p + box(P.PLATE_R - 1, P.STOP_POST_R + P.STOP_POST_D / 2 + 1, -P.STOP_TAB_W / 2, P.STOP_TAB_W / 2, z0, z1)  # stop tab, front
```

```python
def servo_crank():
    """Bolts to the pan servo's round horn; carries the far pin of the parallelogram."""
    z0 = P.Z_SERVO_HORN_TOP
    z1 = P.Z_CRANK_TOP
    sx, sy = P.PAN_SERVO_XY
    arm = box(sx - P.CRANK_L - 4, sx + 4, sy - 4, sy + 4, z0, z1)
    arm = arm + cyl_z(P.HORN_D / 2 + 3, z0, z1, sx, sy) + cyl_z(4, z0, z1, sx - P.CRANK_L, sy)
    arm = arm - cyl_z(P.HORN_D / 2 + P.CLEAR / 2, z0 - 1, z0 + P.HORN_T, sx, sy)      # horn pocket from below
    for a in (0, 90, 180, 270):
        x, y, _ = _polar(P.HORN_SCREW_R, a, 0)
        arm = arm - cyl_z(P.M2_5_CLEAR / 2, z0 - 1, z1 + 1, sx + x, sy + y)
    arm = arm - cyl_z(2.5, z0 - 1, z1 + 1, sx, sy)                                     # horn screw head
    arm = insert_holes(arm, [(sx - P.CRANK_L, sy, z1)])
    return arm


@part("pan_link")
def pan_link():
    """Joins the plate's pin to the servo crank's pin. Length is the centre distance, exactly."""
    z0 = P.Z_CRANK_TOP
    z1 = P.Z_LINK_TOP
    eye = P.M3_CLEAR / 2 + 3.0
    a = (-P.CRANK_L, 0.0)
    b = (-P.CRANK_L - P.PAN_OFFSET, 0.0)
    bar = box(b[0], a[0], -3.0, 3.0, z0, z1)
    link = bar + cyl_z(eye, z0, z1, *a) + cyl_z(eye, z0, z1, *b)
    link = link - cyl_z(P.M3_CLEAR / 2, z0 - 1, z1 + 1, *a) - cyl_z(P.M3_CLEAR / 2, z0 - 1, z1 + 1, *b)
    return link


def _yoke_arm(sy):
    """One arm: rises from its foot on the plate to the ear height. sy is +1 or -1."""
    y_in = sy * (P.EAR_OUT_Y + P.YOKE_GAP)
    y_out = y_in + sy * P.YOKE_ARM_T
    y0, y1 = min(y_in, y_out), max(y_in, y_out)
    z0 = P.Z_PLATE_TOP + 4
    arm = box(-P.YOKE_ARM_W / 2, P.YOKE_ARM_W / 2, y0, y1, z0, P.Z_HEAD) + cyl_y(P.YOKE_ARM_W / 2, y0, y1, 0, P.Z_HEAD)
    arm = arm - cyl_z(P.M3_CLEAR / 2, z0 - 1, z0 + 5, -8, (y0 + y1) / 2) - cyl_z(P.M3_CLEAR / 2, z0 - 1, z0 + 5, 8, (y0 + y1) / 2)
    return arm, y0, y1


@part("yoke")
def yoke():

    arm_p, y0p, y1p = _yoke_arm(+1)
    hexagon = Pos(0, (y0p + y1p) / 2, P.Z_HEAD) * Rot(90, 0, 0) * extrude(RegularPolygon(P.COUPLER_HEX_AF / math.sqrt(3) + P.CLEAR / 2, 6), P.YOKE_ARM_T + 2, both=True)
    arm_p = arm_p - hexagon
    arm_p = arm_p - cyl_y(P.M3_CLEAR / 2, y0p - 1, y1p + 1, 0, P.Z_HEAD + P.YOKE_ARM_W / 2 - 3)  # cross screw locks the hex
    arm_m, y0m, y1m = _yoke_arm(-1)
    arm_m = arm_m - cyl_y(P.M4_PIN / 2 + 0.05, y0m - 1, y1m + 1, 0, P.Z_HEAD)
    # tilt stop pegs reach inward from the arm's inner face to meet the ear boss's tab
    for deg in P.TILT_STOP:

        z = P.Z_HEAD + P.TILT_STOP_TAB_R * math.sin(math.radians(a))
        arm_m = arm_m + cyl_y(2.5, y1m - 0.01, -(P.HEAD_R + 1.0), x, z)

    bridge = box(-P.YOKE_ARM_W / 2, P.YOKE_ARM_W / 2, y0m, y1p, P.Z_PLATE_TOP + 4, P.Z_PLATE_TOP + 8)
```

```python
import math
from build123d import Pos, Rot, Box
import params as P
from mech import part
from mech.common import cyl_z, cyl_y, cyl_x, box, insert_holes


def _polar(r, deg):
    return r * math.cos(math.radians(deg)), r * math.sin(math.radians(deg))


@part("belt_flange_lower", section="base")
def belt_flange_lower():
    """Ring inside the base's rim with the inserts the belt screws go into."""
    z1 = P.Z_BELT
    z0 = z1 - 2 * P.RING_T
    r_out = P.ring_r_out(P.BASE_PROFILE, z0)
    ring = cyl_z(r_out, z0, z1) - cyl_z(P.FLANGE_R_IN, z0 - 1, z1 + 1)
    return insert_holes(ring, [(*_polar(P.FLANGE_SCREW_R, a), z1) for a in P.FLANGE_SCREW_ANGLES], depth=P.INSERT_DEPTH + 2)


@part("belt_flange_upper", section="torso")
def belt_flange_upper():
    """Ring inside the torso's skirt: belt screws pass down through it, chassis screws go into its top."""
    z0 = P.Z_BASE_TOP
    z1 = z0 + P.RING_T
    r_out = P.ring_r_out(P.TORSO_PROFILE, z1)

    for a in P.FLANGE_SCREW_ANGLES:
        x, y = _polar(P.FLANGE_SCREW_R, a)
        ring = ring - cyl_z(P.M3_CLEAR / 2, z0 - 1, z1 + 1, x, y)
```

```python
@part("tank_head")

    R = P.CAN_THREAD_MAJOR / 2 + 3.0

    thread = IsoThread(major_diameter=P.CAN_THREAD_MAJOR + 0.4, pitch=P.CAN_THREAD_PITCH,
```

```python
"""Blender-side helpers. Runs inside Blender's Python only."""
import math
import os
import sys
from pathlib import Path

import bpy
import bmesh

CAD = Path(__file__).resolve().parents[1]
if str(CAD) not in sys.path:
    sys.path.insert(0, str(CAD))
import params as P  # noqa: E402

RAW = CAD / "out" / "raw"


def fresh_scene():
    bpy.ops.wm.read_factory_settings(use_empty=True)
    sc = bpy.context.scene
    sc.unit_settings.system = "METRIC"
    sc.unit_settings.scale_length = 0.001
    return sc


def _link(name, bm):
    bmesh.ops.recalc_face_normals(bm, faces=bm.faces)
    me = bpy.data.meshes.new(name)
    bm.to_mesh(me)
    bm.free()
    ob = bpy.data.objects.new(name, me)
    bpy.context.scene.collection.objects.link(ob)
    return ob


def revolve(name, profile, segments=96, lean=None):
    """Surface of revolution of (r, z) points. r == 0 closes that end.

    `lean(z)` returns an X offset applied to each ring, for a hat that bends forward.
    Open ends (r > 0 at either extreme) stay open; solidify closes them into a rim.
    """
    bm = bmesh.new()
    rows = []
    for r, z in profile:
        dx = lean(z) if lean else 0.0
        if r <= 0:
            rows.append([bm.verts.new((dx, 0, z))])
        else:
            rows.append([bm.verts.new((dx + r * math.cos(2 * math.pi * i / segments),
                                       r * math.sin(2 * math.pi * i / segments), z)) for i in range(segments)])
    for a, b in zip(rows, rows[1:]):
        for i in range(segments):
            if len(a) == 1:
                bm.faces.new((a[0], b[i], b[(i + 1) % segments]))
            elif len(b) == 1:
                bm.faces.new((a[i], b[0], a[(i + 1) % segments]))
            else:
                bm.faces.new((a[i], a[(i + 1) % segments], b[(i + 1) % segments], b[i]))
    return _link(name, bm)


def sphere(name, r, loc, segments=48):
    bpy.ops.mesh.primitive_uv_sphere_add(radius=r, location=loc, segments=segments, ring_count=segments // 2)
    ob = bpy.context.object
    ob.name = name
    return ob


def ellipsoid(name, radii, loc, rot=(0, 0, 0)):
    ob = sphere(name, 1.0, loc)
    ob.scale = radii
    ob.rotation_euler = tuple(math.radians(a) for a in rot)
    return ob


def subdivide(ob, levels=2):
    m = ob.modifiers.new("sub", "SUBSURF")
    m.levels = m.render_levels = levels
    bpy.context.view_layer.objects.active = ob
    bpy.ops.object.modifier_apply(modifier=m.name)


def join_remesh(name, objects, voxel=1.0):
    """Join many closed meshes into one watertight solid."""
    bpy.ops.object.select_all(action="DESELECT")
    for o in objects:
        o.select_set(True)
    bpy.context.view_layer.objects.active = objects[0]
    bpy.ops.object.transform_apply(scale=True, rotation=True, location=False)
    bpy.ops.object.join()
    ob = bpy.context.object
    ob.name = name
    ob.data.remesh_voxel_size = voxel
    ob.data.remesh_voxel_adaptivity = 0.0
    bpy.ops.object.voxel_remesh()
    return ob


def finish(ob, displace=0.0, noise_scale=6.0, solidify=True, wall=P.WALL):
    """Outward-only texture, then a wall of constant thickness grown inward."""
    if displace > 0:
        tex = bpy.data.textures.new(ob.name + "_tex", "CLOUDS")
        tex.noise_scale = noise_scale
        d = ob.modifiers.new("disp", "DISPLACE")
        d.texture = tex
        d.strength = displace
        d.mid_level = 0.0
        d.direction = "NORMAL"
    if solidify:
        s = ob.modifiers.new("solid", "SOLIDIFY")
        s.thickness = wall
        s.offset = -1
        s.use_even_offset = True
    bpy.context.view_layer.objects.active = ob
    for mod in list(ob.modifiers):
        bpy.ops.object.modifier_apply(modifier=mod.name)
    return ob


def export_raw(ob, name):
    RAW.mkdir(parents=True, exist_ok=True)
    bpy.ops.object.select_all(action="DESELECT")
    ob.select_set(True)
    bpy.ops.wm.stl_export(filepath=str(RAW / f"{name}.stl"), export_selected_objects=True)
    print(f"raw   {name}: {len(ob.data.polygons)} faces")
```

```python
    ob = revolve("hat", profile, lean=lean)
    subdivide(ob, 2)
```

```python
"""Turn raw Blender sections into printable ones with manifold booleans.

For each shell section: union the build123d interface parts registered for it, subtract the
openings, then split where the spec says. Everything here is trimesh + manifold3d; nothing
touches Blender.
"""
import math
import sys
from pathlib import Path

import numpy as np
import trimesh

CAD = Path(__file__).resolve().parent
sys.path.insert(0, str(CAD))
import params as P  # noqa: E402
import mech.turntable, mech.torso, mech.head, mech.base  # noqa: E402,F401
from mech import INTERFACES  # noqa: E402

RAW, STL = CAD / "out" / "raw", CAD / "out" / "stl"
ENGINE = "manifold"


def load(name):
    return trimesh.load(RAW / f"{name}.stl") if (RAW / f"{name}.stl").exists() else trimesh.load(STL / f"{name}.stl")


def union(*meshes):
    return trimesh.boolean.union(list(meshes), engine=ENGINE)


def cut(mesh, *cutters):
    return trimesh.boolean.difference([mesh, *cutters], engine=ENGINE)


def box(x0, x1, y0, y1, z0, z1):
    b = trimesh.creation.box(extents=[x1 - x0, y1 - y0, z1 - z0])
    b.apply_translation([(x0 + x1) / 2, (y0 + y1) / 2, (z0 + z1) / 2])
    return b


def cyl(r, length, axis, at):
    c = trimesh.creation.cylinder(radius=r, height=length, sections=64)
    if axis == "x":
        c.apply_transform(trimesh.transformations.rotation_matrix(math.pi / 2, (0, 1, 0)))
    elif axis == "y":
        c.apply_transform(trimesh.transformations.rotation_matrix(math.pi / 2, (1, 0, 0)))
    c.apply_translation(at)
    return c


def sphere(r, at):
    s = trimesh.creation.icosphere(subdivisions=4, radius=r)
    s.apply_translation(at)
    return s


def with_interfaces(mesh, section):
    parts = [trimesh.load(STL / f"{n}.stl") for n in INTERFACES.get(section, [])]
    return union(mesh, *parts) if parts else mesh


def save(mesh, name):
    STL.mkdir(parents=True, exist_ok=True)
    assert mesh.is_watertight, f"{name} is not watertight"
    mesh.export(STL / f"{name}.stl")
    print(f"stl   {name}: {len(mesh.faces)} faces, {mesh.is_watertight}")


def base():
    m = with_interfaces(load("base"), "base")
    r_floor = P.shell_r(P.BASE_PROFILE, 0) + 5
    arches = [cyl(P.DRAIN_ARCH_W / 2, 400, "x", (0, 0, 0)).apply_transform(
        trimesh.transformations.rotation_matrix(math.radians(a), (0, 0, 1))) for a in (0, 45, 90, 135)]
    arches = [a.apply_translation((0, 0, -P.DRAIN_ARCH_W / 2 + P.DRAIN_ARCH_H)) for a in arches]
    stakes = [cyl(P.STAKE_HOLE_D / 2, 60, "z", (P.STAKE_HOLE_R * math.cos(math.radians(a)), P.STAKE_HOLE_R * math.sin(math.radians(a)), P.Z_FLOOR))
              for a in (45, 135, 225, 315)]
    filler = cyl(P.FILLER_D / 2 + 2.5, 60, "x", (-P.shell_r(P.BASE_PROFILE, P.Z_FILLER), 0, P.Z_FILLER))
    m = cut(m, *arches, *stakes, filler)
    # the base is a cup: open its top so the divider drops in (the revolve was open there already;
    # this only trims anything the remesh grew across the rim)
    m = cut(m, cyl(P.shell_r(P.BASE_PROFILE, P.Z_BELT) - P.WALL, 2 * P.RING_T + 20, "z", (0, 0, P.Z_BASE_TOP + 10 - P.RING_T)))
    save(m, "base")


def torso():
    m = with_interfaces(load("torso"), "torso")
    xw = P.shell_r(P.TORSO_PROFILE, P.Z_LENS)
    window = box(xw - 30, xw + 30, -P.WINDOW_W / 2, P.WINDOW_W / 2, P.Z_LENS - P.WINDOW_H / 2, P.Z_LENS + P.WINDOW_H / 2)
    xb = -P.shell_r(P.TORSO_PROFILE, P.Z_FAN)
    exhaust = cyl(P.FAN / 2 - 2, 60, "x", (xb, 0, P.Z_FAN))
    xi = -P.shell_r(P.TORSO_PROFILE, P.Z_VENT_IN)
    intake = box(xi - 30, xi + 30, -P.VENT_IN_W / 2, P.VENT_IN_W / 2, P.Z_VENT_IN - P.VENT_IN_H / 2, P.Z_VENT_IN + P.VENT_IN_H / 2)
    top = cyl(P.RING_R_IN, 100, "z", (0, 0, P.Z_TORSO_TOP + 40))                     # neck opening
    skirt = cyl(P.shell_r(P.BASE_PROFILE, P.Z_BASE_TOP) + P.CLEAR, 2 * (P.Z_BASE_TOP - P.Z_BELT) + 0.2, "z", (0, 0, P.Z_BELT))
    m = cut(m, window, exhaust, intake, top, skirt)
    save(m, "torso")


def beard():
    m = load("beard")
    # shorten the back: everything behind x = -20 and below BEARD_BOTTOM_BACK_Z goes
    m = cut(m, box(-300, -20, -300, 300, 0, P.BEARD_BOTTOM_BACK_Z))
    # collar screw bosses are on the torso side; the collar gets three through holes
    for a in (90, 210, 330):
        r = P.shell_r(P.TORSO_PROFILE, 388)
        m = cut(m, cyl(P.M3_CLEAR / 2, 40, "x", (0, 0, 388)).apply_transform(
            trimesh.transformations.rotation_matrix(math.radians(a), (0, 0, 1))).apply_translation(
            (r * math.cos(math.radians(a)), r * math.sin(math.radians(a)), 0)))
    save(m, "beard")


def head():
    raw = load("head")
    Z = P.Z_HEAD
    # ears: the coupler passes through the +Y wall, the ear boss is unioned on -Y
    bore = cyl(P.COUPLER_D / 2 + P.CLEAR, 40, "y", (0, P.HEAD_R, Z))
    bottom = cyl(P.HEAD_OPENING_R, 30, "z", (0, 0, Z - P.HEAD_R))
    mouth = cyl(P.MOUTH_D / 2, 40, "x", (P.HEAD_R, 0, P.Z_MOUTH))
    raw = cut(raw, bore, bottom, mouth)
    front = box(P.FACE_SPLIT_X, 200, -200, 200, 0, 700)
    back = box(-200, P.FACE_SPLIT_X, -200, 200, 0, 700)
    face = with_interfaces(trimesh.boolean.intersection([raw, front], engine=ENGINE), "face")
    head_back = with_interfaces(trimesh.boolean.intersection([raw, back], engine=ENGINE), "head_back")
    save(face, "face")
    save(head_back, "head_back")


def hat():
    m = load("hat")
    m = cut(m, sphere(P.HEAD_R + P.CLEAR, (0, 0, P.Z_HEAD)))      # seats on the head
    save(m, "hat")


def main():
    base()
    torso()
    beard()
    head()
    hat()


if __name__ == "__main__":
    main()
```

```python
"""Render every printable part and the assembled gnome. Look at these after every change."""
import math
import sys
from pathlib import Path
import bpy

CAD = Path(__file__).resolve().parents[1]
sys.path.insert(0, str(CAD))
import params as P  # noqa: E402

STL = CAD / "out" / "stl"
PNG = CAD / "out" / "preview"
SECTIONS = ("base", "torso", "beard", "head_back", "face", "hat")
VIEWS = {"front": ((900, 0, 275), (math.pi / 2, 0, math.pi / 2)),
         "side": ((0, -900, 275), (math.pi / 2, 0, 0)),
         "iso": ((650, -650, 600), (math.radians(60), 0, math.radians(45)))}


def scene(scale):
    bpy.ops.wm.read_factory_settings(use_empty=True)
    sc = bpy.context.scene
    sc.render.engine = "BLENDER_WORKBENCH"
    sc.render.resolution_x = sc.render.resolution_y = 900
    sc.display.shading.light = "STUDIO"
    sc.display.shading.color_type = "SINGLE"
    cam = bpy.data.cameras.new("c")
    cam.type = "ORTHO"
    cam.ortho_scale = scale
    co = bpy.data.objects.new("c", cam)
    sc.collection.objects.link(co)
    sc.camera = co
    return sc, co


def render(sc, co, name):
    PNG.mkdir(parents=True, exist_ok=True)
    for view, (loc, rot) in VIEWS.items():
        co.location, co.rotation_euler = loc, rot
        sc.render.filepath = str(PNG / f"{name}_{view}.png")
        bpy.ops.render.render(write_still=True)


def load_all(names):
    for n in names:
        bpy.ops.wm.stl_import(filepath=str(STL / f"{n}.stl"))


def main():
    sc, co = scene(650)
    load_all(SECTIONS)
    render(sc, co, "gnome")
    for n in SECTIONS:
        sc, co = scene(300)
        load_all([n])
        ob = bpy.context.selected_objects[0]
        lo, hi = P.SECTION_Z[n]
        co.location = (co.location[0], co.location[1], (lo + hi) / 2)
        for view, (loc, rot) in VIEWS.items():
            co.location = (loc[0], loc[1], (lo + hi) / 2)
            co.rotation_euler = rot
            sc.render.filepath = str(PNG / f"{n}_{view}.png")
            bpy.ops.render.render(write_still=True)
    # the mechanism alone, from the STL the mech stage wrote
    sc, co = scene(220)
    mech = [p.stem for p in STL.glob("*.stl") if p.stem not in SECTIONS]
    load_all(mech)
    for view, (loc, rot) in VIEWS.items():
        co.location = (loc[0], loc[1], 330)
        co.rotation_euler = rot
        sc.render.filepath = str(PNG / f"mechanism_{view}.png")
        bpy.ops.render.render(write_still=True)


main()
```

```markdown
# Printed parts

Every printed part of the gnome, generated from `params.py`. Mechanism parts are STEP and STL
from build123d; shell sections are STL from Blender plus manifold booleans. Nothing generated
is committed.

## Build

    uv venv --python 3.11 .venv-cad
    uv pip install --python .venv-cad/bin/python -r cad/requirements.txt
    .venv-cad/bin/python cad/build.py            # mech, shell, assemble, preview
    .venv-cad/bin/pytest cad/tests -q            # 35 tests, the shell ones need a build first

Blender 5.2 at `/Applications/Blender.app` is used headless; set `BLENDER` to point elsewhere.

Outputs: `out/step/` (mechanism, plus `mechanism_assembly.step`), `out/stl/` (everything the
slicer takes), `out/preview/` (renders, front/side/iso, per part and assembled).

## Before printing anything that touches a bought part

Measure the part and change the number in `params.py`, then rebuild. The defaults are
listing-typical guesses:

| Parameter | What to measure |
|---|---|
| `BEARING_SQ`, `BEARING_T`, `BEARING_OPEN`, `BEARING_PITCH`, `BEARING_HOLE` | the lazy susan |
| `CANISTER`, `CAN_THREAD_MAJOR`, `CAN_THREAD_PITCH`, `CAN_NECK_ID` | the 3 L canister and its neck |
| `PUMP`, `PUMP_FEET` | the pump's body and the pitch of its mounting feet |
| `VALVE` | the solenoid valve |
| `DS3218`, `MG996R`, `HORN_D`, `HORN_SCREW_R` | the servos as delivered, and the round horns in the bag |
| `XL4015_HOLES` | the buck converters' mounting holes |
| `LENS_CLIP_T` | how far the clip-on lens stands proud of the phone's back |

Print the tank head first, alone: it is the fit coupon for the canister thread. Then the phone
sled: it is the fit coupon for the phone.

## Which part is which

| File | Part | Material |
|---|---|---|
| `base` | Boots, coat hem, floor with drain arches and stake holes; belt flange lower with four inserts inside its rim | PETG |
| `divider` | The base's lid. Slice at 100 % infill, 6 perimeters. Sealed to the base with a PU bead | PETG |
| `torso` | Belly and coat; window with hood; intake and exhaust openings; belt flange upper, deck ring and fan frame inside | PETG |
| `chassis` | Bolts to the torso flange; carries the sled and the electronics deck | PETG |
| `phone_sled` | The phone stands in it camera-down, screen to the back. Fits one way | PETG |
| `electronics_deck` | ESP32, two XL4015, three MOSFET modules, fuse holder | PETG |
| `deck`, `plate`, `shaft`, `servo_crank`, `pan_link`, `yoke`, `coupler` | The neck and pan drive | PETG, 4 perimeters |
| `beard` | Collar around the neck, beard down the chest; three screws from inside the torso | PETG |
| `head_back` | Back of the head with the ear boss, tilt bulkhead and face lip inside | ASA if enclosed, else PETG |
| `face` | Nose, cheeks, brows, moustache, mouth; nozzle bosses inside | Same |
| `nozzle_holder` | Behind the mouth; brass nozzle pressed in | Same |
| `hat` | Bonded on the head, seats on a spherical cut | PETG |
| `tank_head`, `tank_cradle`, `filler_cap`, `pump_mount` | The wet zone | PETG |

Fasteners: M3 heat-set inserts wherever a hole is 4.0 mm; M3 × 25 at the belt; M3 × 8 elsewhere;
one M4 × 40 pin through the −Y ear; M2.5 for the two servo horns.

`test_params.py`: the layout arithmetic. `test_mech.py`: every part is one valid solid within
```
