# Printed Parts (CAD) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every printed part of the gnome as files the slicer can take — STEP and STL for the mechanism, STL for the sculpted shell — generated from one parameters module, checked by tests, and previewed by renders.

**Architecture:** `cad/params.py` holds every dimension. `cad/mech/*.py` builds the mechanism in build123d and exports STEP + STL. `cad/shell/*.py` sculpts the raw shell sections in Blender (headless) and exports closed meshes. `cad/assemble.py` unions the build123d interface parts into the raw sections and cuts the openings and splits with manifold3d, writing the printable sections. `cad/build.py` runs the stages in order. Tests check validity, size, fit and clearance without a printer; previews are the look test.

**Tech Stack:** Python 3.11 in `.venv-cad` (build123d 0.13, bd_warehouse, trimesh, manifold3d, rtree, numpy, pytest), Blender 5.2 LTS at `/Applications/Blender.app` with its bundled Python.

**Spec:** `docs/superpowers/specs/2026-09-22-cad-parts-design.md` (see its Revisions section: the as-built heights are in `cad/params.py`). Read it first; the numbers below come from it and from three probes run while planning: build123d exports a valid STEP on this Mac, Blender's own exact boolean leaves non-manifold meshes on subdivided input while manifold3d does not, and a voxel-remeshed, solidified Blender mesh survives manifold unions and cuts watertight.

**Coordinate system, everywhere:** millimetres, Z up, +X is the direction the gnome faces, origin at the centre of the floor.

**Conventions:**
- Commit after every task with the repository's usual style (a subject line, a body that says why, and the attribution trailer the session's system reminder specifies).
- `cad/out/` is ignored by git. Never commit generated STEP, STL or PNG.
- Run tests with `.venv-cad/bin/pytest cad/tests -q` from the repository root.
- Blender is `/Applications/Blender.app/Contents/MacOS/Blender`; `build.py` reads `BLENDER` from the environment to override it.

| `cad/mech/base.py` | Tank head, tank cradle, filler cap, pump mount |

| `cad/shell/common.py` | Blender helpers: `revolve`, `sphere`, `ellipsoid`, `join_remesh`, `finish`, `export_raw`, `run` |
| `cad/shell/body.py` | `base_raw.stl`, `torso_raw.stl` |
| `cad/shell/head.py` | `head_raw.stl`, `hat_raw.stl` |
| `cad/shell/beard.py` | `beard_raw.stl` |
| `cad/shell/preview.py` | Workbench renders of every printable part and of the assembly |
| `cad/assemble.py` | trimesh + manifold3d: raw section + interface STLs − openings − splits → printable STL |
| `cad/build.py` | Stages: `mech`, `shell`, `assemble`, `preview`, or all |
| `cad/tests/conftest.py` | Puts `cad/` on `sys.path`; fixtures that build parts once per session |

| `cad/tests/test_mech.py` | Validity, size, fits, stops vs the protocol fixture, parallelogram |
| `cad/tests/test_shell.py` | Watertightness, size, cavities, openings, nod clearance (skipped when `cad/out/stl/` has no assembled sections) |

    px, py = p

def shell_r(profile, z):
    """Outer radius of a revolved profile at height z, linear between points.

    Where the profile steps (two points at one z) the larger radius wins, so a ring sized
    from it never lands inside a step.
    """
    pts = sorted(profile, key=lambda p: p[1])
    if z <= pts[0][1]:
        return pts[0][0]
    if z >= pts[-1][1]:
        return pts[-1][0]
    found = []
    for (r0, z0), (r1, z1) in zip(pts, pts[1:]):
        if z0 <= z <= z1:
            found.append(max(r0, r1) if z1 == z0 else r0 + (r1 - r0) * (z - z0) / (z1 - z0))
    return max(found)


def ring_r_out(profile, z0, z1=None):
    """Outer radius for an interface ring spanning z0..z1: embedded 1.2 mm into the wall at the
    ring's narrowest height, so it never breaks through the skin where the wall tapers."""
    zs = (z0,) if z1 is None else (z0, z1)
    return min(shell_r(profile, z) for z in zs) - WALL + 1.2

from pathlib import Path
from build123d import Box, Cylinder, Pos, Rot, Part, export_step, export_stl
import params as P

OUT = Path(__file__).resolve().parents[1] / "out"
STEP = OUT / "step"
STL = OUT / "stl"


def export(part: Part, name: str) -> None:
    STEP.mkdir(parents=True, exist_ok=True)
    STL.mkdir(parents=True, exist_ok=True)
    if not export_step(part, str(STEP / f"{name}.step")):
        raise RuntimeError(f"STEP export failed: {name}")
    # 0.05 mm chordal tolerance: coarser than build123d's default, fine for a 0.6 mm nozzle
    if not export_stl(part, str(STL / f"{name}.stl"), tolerance=0.05, angular_tolerance=0.1):
        raise RuntimeError(f"STL export failed: {name}")


def cyl_z(r, z0, z1, x=0.0, y=0.0):
    """A cylinder along Z from z0 to z1."""
    return Pos(x, y, (z0 + z1) / 2) * Cylinder(r, z1 - z0)


def cyl_y(r, y0, y1, x=0.0, z=0.0):
    return Pos(x, (y0 + y1) / 2, z) * Rot(90, 0, 0) * Cylinder(r, y1 - y0)


def cyl_x(r, x0, x1, y=0.0, z=0.0):
    return Pos((x0 + x1) / 2, y, z) * Rot(0, 90, 0) * Cylinder(r, x1 - x0)


def box(x0, x1, y0, y1, z0, z1):
    return Pos((x0 + x1) / 2, (y0 + y1) / 2, (z0 + z1) / 2) * Box(x1 - x0, y1 - y0, z1 - z0)


def servo_body(spec, shaft_xyz, axis="z"):
    """A servo as a solid, for clearance checks and cutters.

    `shaft_xyz` is where the output shaft leaves the body and `axis` is the shaft direction.
    Only the orientations this design uses exist:
    "-z": shaft down, body above the shaft face, length running +X from the shaft end (pan);
    "y":  shaft along +Y, body behind the shaft face, length running -Z from the shaft end (tilt).
    """
    L, W, H = spec["body"]
    off = spec["shaft_off"]
    sx, sy, sz = shaft_xyz
    if axis == "-z":
        return box(sx - off, sx + (L - off), sy - W / 2, sy + W / 2, sz, sz + H)
    if axis == "y":
        return box(sx - W / 2, sx + W / 2, sy - H, sy, sz - (L - off), sz + off)
    raise ValueError(axis)


def phone_body():
    """The iPhone standing upright, camera end down, screen facing -X, centred; its camera is at CAM_Y."""
    return box(P.PHONE_FRONT_X, P.PHONE_BACK_X,
               P.PHONE_Y_OFFSET - P.PHONE_W / 2, P.PHONE_Y_OFFSET + P.PHONE_W / 2,
               P.PHONE_BOTTOM_Z, P.PHONE_BOTTOM_Z + P.PHONE_L)


def canister_body():
    L, W, H = P.CANISTER
    cx, cy = P.CANISTER_XY
    return box(cx - L / 2, cx + L / 2, cy - W / 2, cy + W / 2, P.Z_FLOOR + 6, P.Z_FLOOR + 6 + H)


def pump_body():
    L, W, H = P.PUMP
    cx, cy = P.PUMP_XY
    return box(cx - L / 2, cx + L / 2, cy - W / 2, cy + W / 2, P.Z_FLOOR + 10, P.Z_FLOOR + 10 + H)


def insert_holes(part, points, depth=P.INSERT_DEPTH, r=P.INSERT_D / 2, direction="down"):
    """Blind holes for heat-set inserts, drilled from each (x, y, z) point."""
    for x, y, z in points:
        if direction == "down":
            part = part - cyl_z(r, z - depth, z + 0.01, x, y)
        elif direction == "up":
            part = part - cyl_z(r, z - 0.01, z + depth, x, y)
    return part
```

"""The neck: what the head stands on and what turns it."""
import math
from build123d import Cylinder, Box, Pos, Rot, RegularPolygon, extrude, Plane, Axis
import params as P
from mech import part
from mech.common import cyl_z, cyl_y, box, insert_holes, servo_body


def _polar(r, deg, z):
    return (r * math.cos(math.radians(deg)), r * math.sin(math.radians(deg)), z)


def _notch(z0, z1):
    (x0, y0), (x1, y1) = P.PAN_NOTCH
    return box(x0, x1, y0, y1, z0, z1)


def _servo_tab_holes():
    L, W, H = P.DS3218["body"]
    along, across = P.DS3218["holes"]
    sx, sy = P.PAN_SERVO_XY
    cy = sy + P.DS3218["shaft_off"] - L / 2      # body centre along Y
    return [(sx + dx, cy + dy) for dx in (-across / 2, across / 2) for dy in (-along / 2, along / 2)]


@part("deck_ring", section="torso")
def deck_ring():
    """Narrow annulus the deck bolts to, joined to the shoulders' wall by four webs. Unioned into the torso.

    Narrow on purpose: the phone's top passes outside it (PHONE_FRONT_X > RING_R_OUT). Cut
    away around the pan servo, whose body hangs through it with its tab screws and nuts.
    """
    z1 = P.Z_DECK - P.DECK_T
    z0 = z1 - P.RING_T
    ring = cyl_z(P.RING_R_OUT, z0, z1) - cyl_z(P.RING_R_IN, z0 - 1, z1 + 1)
    r_wall = P.ring_r_out(P.TORSO_PROFILE, z0, z1)
    for a in P.DECK_SCREW_ANGLES:
        ring = ring + box(P.RING_R_OUT - 2, r_wall, -P.RING_WEB_W / 2, P.RING_WEB_W / 2, z0, z1).rotate(Axis.Z, a)
    (x0, y0), (x1, y1) = P.PAN_RING_CUT
    ring = ring - box(x0, x1, y0, y1, z0 - 1, z1 + 1)
    return insert_holes(ring, [_polar(P.DECK_SCREW_R, a, z1) for a in P.DECK_SCREW_ANGLES], depth=P.RING_T - 1)


@part("deck")
def deck():
    """Carries the bearing's fixed ring, the pan servo and the pan hard stops."""
    z1, z0 = P.Z_DECK, P.Z_DECK - P.DECK_T
    d = cyl_z(P.DECK_R, z0, z1)
    d = d - cyl_z(P.SHAFT_OD / 2 + P.CLEAR + 1.0, z0 - 1, z1 + 1)          # shaft passes with room
    for a in (45, 135, 225, 315):                                          # bearing screws
        x, y, _ = _polar(P.BEARING_PITCH / 2 * math.sqrt(2), a, 0)
        d = d - cyl_z(P.BEARING_HOLE / 2, z0 - 1, z1 + 1, x, y)
    for a in P.DECK_SCREW_ANGLES:                                          # down into the ring
        x, y, _ = _polar(P.DECK_SCREW_R, a, 0)
        d = d - cyl_z(P.M3_CLEAR / 2, z0 - 1, z1 + 1, x, y)
    d = d - _notch(z0 - 1, z1 + 1)                                         # pan servo body
    for x, y in _servo_tab_holes():                                        # tab screws, nut below
        d = d - cyl_z(P.M3_CLEAR / 2, z0 - 1, z1 + 1, x, y)
        d = d - Pos(x, y, z0 + P.NUT_M3_T / 2 - 0.01) * extrude(RegularPolygon(P.NUT_M3_AF / math.sqrt(3), 6), P.NUT_M3_T)
    # hard-stop posts either side of the plate's front tab
    half_tab = math.degrees(math.atan2(P.STOP_TAB_W / 2, P.PLATE_R))
    for sign in (1, -1):
        x, y, _ = _polar(P.STOP_POST_R, sign * (P.PAN_STOP_DEG + half_tab + math.degrees(math.atan2(P.STOP_POST_D / 2, P.STOP_POST_R))), 0)
        d = d + cyl_z(P.STOP_POST_D / 2, z1 - 0.01, P.Z_PLATE_TOP + 1, x, y)
    return d


@part("plate")
def plate():
    """The head's foundation: sits on the bearing, carries the shaft, the crank pin and the yoke."""
    z0 = P.Z_DECK + P.BEARING_T
    z1 = P.Z_PLATE_TOP
    p = cyl_z(P.PLATE_R, z0, z1)
    p = p - cyl_z(P.SHAFT_OD / 2 + 0.1, z0 - 1, z1 + 1)                    # shaft bonds in here
    for a in (45, 135, 225, 315):                                          # bearing's top ring
        x, y, _ = _polar(P.BEARING_PITCH / 2 * math.sqrt(2), a, 0)
        p = p - cyl_z(P.BEARING_HOLE / 2, z0 - 1, z1 + 1, x, y)
    p = p + box(P.PLATE_R - 1, P.STOP_POST_R + P.STOP_POST_D / 2 + 1, -P.STOP_TAB_W / 2, P.STOP_TAB_W / 2, z0, z1)  # stop tab, front
    return p


@part("shaft")
def shaft():
    """Hollow, passive: bonded into the plate, turns inside the bearing's opening."""
    z1 = P.Z_PLATE_TOP + 6.0                 # proud of the plate for a flared lip
    z0 = P.Z_DECK - P.DECK_T - 40.0          # well below the deck so the tube's bend stays gentle

    flare = cyl_z(P.SHAFT_OD / 2 + 3, z1 - 3, z1) - cyl_z(P.SHAFT_ID / 2, z1 - 4, z1 + 1)
    return s + flare

@part("yoke")
def yoke():
    """Ring on the plate's rim with two arms. +Y holds the coupler's hex; -Y takes the M4 pin and the tilt stop pegs."""
    z0 = P.Z_PLATE_TOP
    z1 = z0 + P.YOKE_RING_T

        y = y - cyl_z(P.M3_CLEAR / 2, z0 - 1, z1 + 1, px, py)
    for sy in (1, -1):
        y0, y1 = _arm_y(sy)
        foot = box(-P.YOKE_ARM_W / 2, P.YOKE_ARM_W / 2, min(sy * P.YOKE_RING_R_IN, sy * y1), max(sy * P.YOKE_RING_R_IN, sy * y1), z0, z1)

"""Blender-side helpers. Runs inside Blender's Python only."""
import math
import os
import sys
from pathlib import Path

import bpy
import bmesh

CAD = Path(__file__).resolve().parents[1]
if str(CAD) not in sys.path:
    sys.path.insert(0, str(CAD))
import params as P  # noqa: E402

RAW = CAD / "out" / "raw"


def fresh_scene():
    bpy.ops.wm.read_factory_settings(use_empty=True)
    sc = bpy.context.scene
    sc.unit_settings.system = "METRIC"
    sc.unit_settings.scale_length = 0.001
    return sc


def _link(name, bm):
    bmesh.ops.recalc_face_normals(bm, faces=bm.faces)
    me = bpy.data.meshes.new(name)
    bm.to_mesh(me)
    bm.free()
    ob = bpy.data.objects.new(name, me)
    bpy.context.scene.collection.objects.link(ob)
    return ob


def revolve(name, profile, segments=96, lean=None):
    """Surface of revolution of (r, z) points. r == 0 closes that end.

    `lean(z)` returns an X offset applied to each ring, for a hat that bends forward.
    Open ends (r > 0 at either extreme) stay open; solidify closes them into a rim.
    """
    bm = bmesh.new()
    rows = []
    for r, z in profile:
        dx = lean(z) if lean else 0.0
        if r <= 0:
            rows.append([bm.verts.new((dx, 0, z))])
        else:
            rows.append([bm.verts.new((dx + r * math.cos(2 * math.pi * i / segments),
                                       r * math.sin(2 * math.pi * i / segments), z)) for i in range(segments)])
    for a, b in zip(rows, rows[1:]):
        for i in range(segments):
            if len(a) == 1:
                bm.faces.new((a[0], b[i], b[(i + 1) % segments]))
            elif len(b) == 1:
                bm.faces.new((a[i], b[0], a[(i + 1) % segments]))
            else:
                bm.faces.new((a[i], a[(i + 1) % segments], b[(i + 1) % segments], b[i]))
    return _link(name, bm)


def sphere(name, r, loc, segments=48):
    bpy.ops.mesh.primitive_uv_sphere_add(radius=r, location=loc, segments=segments, ring_count=segments // 2)
    ob = bpy.context.object
    ob.name = name
    return ob


def ellipsoid(name, radii, loc, rot=(0, 0, 0)):
    ob = sphere(name, 1.0, loc)
    ob.scale = radii
    ob.rotation_euler = tuple(math.radians(a) for a in rot)
    return ob


def subdivide(ob, levels=2):
    m = ob.modifiers.new("sub", "SUBSURF")
    m.levels = m.render_levels = levels
    bpy.context.view_layer.objects.active = ob
    bpy.ops.object.modifier_apply(modifier=m.name)


def join_remesh(name, objects, voxel=1.0):
    """Join many closed meshes into one watertight solid."""
    bpy.ops.object.select_all(action="DESELECT")
    for o in objects:
        o.select_set(True)
    bpy.context.view_layer.objects.active = objects[0]
    bpy.ops.object.transform_apply(scale=True, rotation=True, location=False)
    bpy.ops.object.join()
    ob = bpy.context.object
    ob.name = name
    ob.data.remesh_voxel_size = voxel
    ob.data.remesh_voxel_adaptivity = 0.0
    bpy.ops.object.voxel_remesh()
    return ob


def finish(ob, displace=0.0, noise_scale=6.0, solidify=True, wall=P.WALL):
    """Outward-only texture, then a wall of constant thickness grown inward."""
    if displace > 0:
        tex = bpy.data.textures.new(ob.name + "_tex", "CLOUDS")
        tex.noise_scale = noise_scale
        d = ob.modifiers.new("disp", "DISPLACE")
        d.texture = tex
        d.strength = displace
        d.mid_level = 0.0
        d.direction = "NORMAL"
    if solidify:
        s = ob.modifiers.new("solid", "SOLIDIFY")
        s.thickness = wall
        s.offset = -1
        s.use_even_offset = True
    bpy.context.view_layer.objects.active = ob
    for mod in list(ob.modifiers):
        bpy.ops.object.modifier_apply(modifier=mod.name)
    return ob


def export_raw(ob, name):
    RAW.mkdir(parents=True, exist_ok=True)
    bpy.ops.object.select_all(action="DESELECT")
    ob.select_set(True)
    bpy.ops.wm.stl_export(filepath=str(RAW / f"{name}.stl"), export_selected_objects=True)
    print(f"raw   {name}: {len(ob.data.polygons)} faces")
```

```python
"""Turn raw Blender sections into printable ones with manifold booleans.

For each shell section: union the build123d interface parts registered for it, subtract the
openings, then split where the spec says. Everything here is trimesh + manifold3d; nothing
touches Blender.
"""
import math
import sys
from pathlib import Path

import numpy as np
import trimesh

CAD = Path(__file__).resolve().parent
sys.path.insert(0, str(CAD))
import params as P  # noqa: E402
import mech.turntable, mech.torso, mech.head, mech.base  # noqa: E402,F401
from mech import INTERFACES  # noqa: E402

RAW, STL = CAD / "out" / "raw", CAD / "out" / "stl"
ENGINE = "manifold"


def load(name):
    return trimesh.load(RAW / f"{name}.stl") if (RAW / f"{name}.stl").exists() else trimesh.load(STL / f"{name}.stl")


def union(*meshes):
    return trimesh.boolean.union(list(meshes), engine=ENGINE)


def cut(mesh, *cutters):
    return trimesh.boolean.difference([mesh, *cutters], engine=ENGINE)


def box(x0, x1, y0, y1, z0, z1):
    b = trimesh.creation.box(extents=[x1 - x0, y1 - y0, z1 - z0])
    b.apply_translation([(x0 + x1) / 2, (y0 + y1) / 2, (z0 + z1) / 2])
    return b


def cyl(r, length, axis, at):
    c = trimesh.creation.cylinder(radius=r, height=length, sections=64)
    if axis == "x":
        c.apply_transform(trimesh.transformations.rotation_matrix(math.pi / 2, (0, 1, 0)))
    elif axis == "y":
        c.apply_transform(trimesh.transformations.rotation_matrix(math.pi / 2, (1, 0, 0)))
    c.apply_translation(at)
    return c


def sphere(r, at):
    s = trimesh.creation.icosphere(subdivisions=4, radius=r)
    s.apply_translation(at)
    return s


def with_interfaces(mesh, section):
    parts = [trimesh.load(STL / f"{n}.stl") for n in INTERFACES.get(section, [])]
    return union(mesh, *parts) if parts else mesh


def save(mesh, name):
    STL.mkdir(parents=True, exist_ok=True)
    assert mesh.is_watertight, f"{name} is not watertight"
    mesh.export(STL / f"{name}.stl")
    print(f"stl   {name}: {len(mesh.faces)} faces, {mesh.is_watertight}")


def base():
    m = with_interfaces(load("base"), "base")
    r_floor = P.shell_r(P.BASE_PROFILE, 0) + 5
    arches = [cyl(P.DRAIN_ARCH_W / 2, 400, "x", (0, 0, 0)).apply_transform(
        trimesh.transformations.rotation_matrix(math.radians(a), (0, 0, 1))) for a in (0, 45, 90, 135)]
    arches = [a.apply_translation((0, 0, -P.DRAIN_ARCH_W / 2 + P.DRAIN_ARCH_H)) for a in arches]
    stakes = [cyl(P.STAKE_HOLE_D / 2, 60, "z", (P.STAKE_HOLE_R * math.cos(math.radians(a)), P.STAKE_HOLE_R * math.sin(math.radians(a)), P.Z_FLOOR))
              for a in (45, 135, 225, 315)]
    filler = cyl(P.FILLER_D / 2 + 2.5, 60, "x", (-P.shell_r(P.BASE_PROFILE, P.Z_FILLER), 0, P.Z_FILLER))
    m = cut(m, *arches, *stakes, filler)
    # the base is a cup: open its top so the divider drops in (the revolve was open there already;
    # this only trims anything the remesh grew across the rim)
    m = cut(m, cyl(P.shell_r(P.BASE_PROFILE, P.Z_BELT) - P.WALL, 2 * P.RING_T + 20, "z", (0, 0, P.Z_BASE_TOP + 10 - P.RING_T)))
    save(m, "base")


def torso():
    m = with_interfaces(load("torso"), "torso")
    xw = P.shell_r(P.TORSO_PROFILE, P.Z_LENS)
    zc = P.Z_LENS + P.WINDOW_Z_BIAS
    window = box(xw - 30, xw + 30, P.CAM_Y - P.WINDOW_W / 2, P.CAM_Y + P.WINDOW_W / 2, zc - P.WINDOW_H / 2, zc + P.WINDOW_H / 2)
    xb = -P.shell_r(P.TORSO_PROFILE, P.Z_FAN)
    exhaust = cyl(P.FAN / 2 - 2, 60, "x", (xb, 0, P.Z_FAN))
    xi = -P.shell_r(P.TORSO_PROFILE, P.Z_VENT_IN)
    intake = box(xi - 30, xi + 30, -P.VENT_IN_W / 2, P.VENT_IN_W / 2, P.Z_VENT_IN - P.VENT_IN_H / 2, P.Z_VENT_IN + P.VENT_IN_H / 2)
    top = cyl(P.RING_R_IN, 100, "z", (0, 0, P.Z_TORSO_TOP + 40))                     # neck opening
    skirt = cyl(P.shell_r(P.BASE_PROFILE, P.Z_BASE_TOP) + P.CLEAR, 2 * (P.Z_BASE_TOP - P.Z_BELT) + 0.2, "z", (0, 0, P.Z_BELT))
    m = cut(m, window, exhaust, intake, top, skirt)
    save(m, "torso")


def beard():
    m = load("beard")
    # shorten the back: everything behind x = -20 and below BEARD_BOTTOM_BACK_Z goes
    m = cut(m, box(-300, -20, -300, 300, 0, P.BEARD_BOTTOM_BACK_Z))
    # collar screw bosses are on the torso side; the collar gets three through holes
    for a in (90, 210, 330):
        z = P.Z_TORSO_TOP - 4
        r = P.shell_r(P.TORSO_PROFILE, z)
        m = cut(m, cyl(P.M3_CLEAR / 2, 40, "x", (0, 0, z)).apply_transform(
            trimesh.transformations.rotation_matrix(math.radians(a), (0, 0, 1))).apply_translation(
            (r * math.cos(math.radians(a)), r * math.sin(math.radians(a)), 0)))
    save(m, "beard")


def head():
    raw = load("head")
    Z = P.Z_HEAD
    # ears: the coupler passes through the +Y wall, the ear boss is unioned on -Y
    bore = cyl(P.COUPLER_D / 2 + P.CLEAR, 40, "y", (0, P.HEAD_R, Z))
    bottom = cyl(P.HEAD_OPENING_R, 30, "z", (0, 0, Z - P.HEAD_R))
    mouth = cyl(P.MOUTH_D / 2, 40, "x", (P.HEAD_R, 0, P.Z_MOUTH))
    raw = cut(raw, bore, bottom, mouth)
    front = box(P.FACE_SPLIT_X, 200, -200, 200, 0, 700)
    back = box(-200, P.FACE_SPLIT_X, -200, 200, 0, 700)
    face = with_interfaces(trimesh.boolean.intersection([raw, front], engine=ENGINE), "face")
    head_back = with_interfaces(trimesh.boolean.intersection([raw, back], engine=ENGINE), "head_back")
    save(face, "face")
    save(head_back, "head_back")


def hat():
    m = load("hat")
    m = cut(m, sphere(P.HEAD_R + P.CLEAR, (0, 0, P.Z_HEAD)))      # seats on the head
    save(m, "hat")


def main():
    base()
    torso()
    beard()
    head()
    hat()


if __name__ == "__main__":
    main()
```

## Post-implementation addendum (2026-09-22/23)

Executed subagent-driven, one implementer per task with an adversarial reviewer after Tasks 1,
2–3 and 4–6. The pattern from the firmware and app plans held: most defects came from the plan,
and every one of them was closed at the parameter level with a test that fails on the old value.
Commits are on `cad/parts`; the spec's §11 carries the same story from the design side.

**Task 1.** The first layout tests failed: `BASE_PROFILE` mixed the floor's points into the outer
skin, and a 138 mm phone did not fit between the chassis and the deck ring. Deck up 8 mm, broad
shoulders under the collar, ring as an annulus on webs, phone centred with its camera 22.5 mm off
the centreline (calibration absorbs it). The review then found the link inside the neck wall at
rest and the servo through the ring: neck to r 76, ring cut around the servo, deck to r 70.

**Tasks 2–3.** Yoke feet stood outside the plate (yoke on a ring instead). Cranks pointing +Y put
the link across the shaft's mouth, and with crank = servo offset the link swept through the pan
axis at +25°; then the servo body could not clear the plate at all. Final: servo under the deck,
shaft down, at (5, −60); 30 mm cranks; the plate's stop tab hangs a column through an arc slot in
the deck to a foot bar. The review then proved the head uninstallable — servo unthreadable onto a
plate inside a 90 mm sphere, no driver paths, coupler boss larger than the wall bore, tilt stops
mirrored, pan crank missing its horn. Final: cradle assembled on the bench, in through the face on
rails, held by a lip and a face-cap stop; boss-less Ø24 coupler from outside with two horn screws
down counterbores; M4 bolt into an insert; head r 48 so the cradle passes the opening; hat brim
34 mm above the axis so it clears the 36 mm arms; separate stop pins; shaft below the link.

**Tasks 4–6.** Ten computed deviations in the torso (bead groove clear of the screws, standoffs on
the plate, lens channel full height, a key that actually keys, a round fan bore) and the base
does not close: a 220 × 140 canister has a 130 mm half-diagonal in a 122 mm circle. Canister
160 × 120 × 105, pump bridged above on cradle towers, belt up 20 mm (589 mm total). The review then
found the phone could never leave its sled (tray open under the deck; chassis wider than the belt
opening): a **belly hatch** — the coat front is a screwed-on panel carrying the window; the sled
slides out forward. Also: M3 × 20 belt screws (25 bottomed out), divider proud 0.3 for the bead,
electronics laid out by name and tested as footprints, nozzle as its own outboard bearing with a
15 mm tube bend, filler rising from the tank head's shoulder, pump tied and valve strapped.

**Tasks 7–9.** Blender sculpts carve the profiles inward (the bed leaves nothing to add), one
swell function per section instead of joined balls; the head's face is relief on the exact sphere
the mechanism was drawn against. The collar's bore left a 33 mm moat around the head: a **neck
shroud** on the plate turns with the head and closes it to 9.3 mm. manifold booleans needed a
sliver filter and a pinch fixer before an STL round trip survived; every section is written, read
back and re-checked. The branch review then took the fixed collar away altogether - at full
nose-down the jet crossed its bore at every pan angle - so the beard moves onto the shroud, to
be sculpted with the reference statue.

**Numbers at the end:** 31 mechanism parts, 6 shell sections, 113 tests in four files, full build
in about half a minute. What the spec's §3 table promised is delivered except the window hood
as a mechanism part (it is sculpted), the vent frames (the intake is a plain mesh-backed
opening), and the beard, which has moved onto the shroud.

**Statue phase (branch `cad/statue`).** The sculpt was thrown away. What replaced it is an
image-to-3D reconstruction of the user's own garden gnome - Hunyuan3D-2mv, run locally from four
photographs - put into the project frame, straightened and mirrored about its own sagittal plane,
scaled to 700 mm and hollowed by SOLIDIFY to a 2.4 mm wall. `cad/statue.py` owns all of that and
writes `out/statue/features.json`: feature heights measured on the mesh where it has a signature,
the cavity's reach from the pan axis every five millimetres, and the trouser legs' centres. Every
other agent reads that file instead of guessing where the skin is, which is the whole point -
the shell stopped being a set of profiles anybody could dimension from.

The sectioning follows from one decision: the head does not nod any more, it turns. Everything
above the beard's bottom edge is a single **bell** on the neck shroud; the coat's belt ring and
two sleeve panels stay fixed, the mitten caps come off the base halves for the bed, and the bell
is swept through ±65° against the fixed pieces every five degrees as a build step rather than a
test. That sweep is what set `PANEL_Y`: at 95 the bell had to be lathed to r 93 and the beard
lost 12 mm of its front, leaving a 14 mm slot you could see the mechanism through; at 105 the
lathe takes 2.3 mm and the gap is the 2 mm the bell needs to turn. The assembler became general
in the same pass - each interface blank is clipped to `cavity_grown` and to the section's own
region, and a piece that touches no wall is left out and said aloud, which is how the deck ring
and the fan frame were caught standing free before either had been reported.

Two things the tests found that the design had not: the nozzle's parting at `Z_MOUTH ± 22` closed
on the jet above +30° of tilt, because the face above the mouth is the nose, so the cutter is now
the jet's own swept envelope through the whole tilt range; and the belly hatch, the window's hood
and the fan's exhaust all disappeared - with the bell lifting off there is nothing to reach
through the belly for, and the fan hangs under the deck and breathes out through the neck gap.

**Numbers at the end of it:** 25 mechanism parts, 10 shell sections, 33 prints, 163 tests in five
files, full build in about a minute. 700 mm tall, 1.8 kg of shell, 1.1 kg of mechanism.

## Addendum, 2026-09-24: the statue review's ten fixes

An adversarial pass over the statue branch, one commit per finding, no geometry changed except
where a part could not be assembled or a wall could not be printed.

**The bottle 2 mm forward of centre.** At x −3 its rear shoulder corners passed the coat's inner
wall with 0.13 mm, which is line-to-line once a blow-moulded bottle's own tolerance is counted.
The rear corners gain about 0.45 mm per millimetre forward and the front corners begin to lose
from +3, so +2 is the balance point: 2.55 mm at the back. Nothing in front of the bottle needed
the old position — the filler hose passes its end, not its front.

**`scipy` in `requirements.txt`.** `statue.py` imports `scipy.sparse` and `scipy.spatial` at
module top and `assemble.py` imports `statue`, so a clone that followed the README's install line
could build neither the statue stage nor `test_shell.py`. Found by a clean-clone reproduction.

**Driver access through the shroud's roof, round radial bores, a hose that misses the bottle.**
Three things the bell hangs on, one of them unassemblable. The four M3 × 10 that carry the 573 g
bell are driven down from inside the shroud's cup with 34 mm of barrel and a closed roof over
them: a 6 mm driver met 71 mm³ of that roof and a 3 mm hex key 17, so the screws could be started
by hand and never tightened. The roof is bored `SHROUD_ACCESS_D` over each one. The six radial
insert bores were a box intersected with a cylinder — a 4 × 4 mm square hole a round insert
touched at four corners — and are drilled cylinders now. `STOP_PIN_SEAT_D` went from a 6.00 pin
in a 6.10 seat, which is a split deck in the hand, to 6.4 and *glue it*. And the filler hose cut
116 mm³ out of the bottle and 7.6 cm³ out of the base's belt ring, which nothing was checking:
`HOSE_OD` is 8 now, the neck has come in to x 42, and the route is four straight legs that touch
nothing.

**Tests that could not fail, and a scene that draws the parts where they are.** `test_params`'
reach table fell back to fifteen rows of the fit report when `features.json` was missing, so in a
clone without `cad/in/` five layout tests passed against numbers the mesh had contradicted; a
dead `... or True` guarded a belief about the legs the mesh disproved; and `statue.py`'s bell
sweep computed the worst overlap, printed it and threw it away, so the build could not fail on
it. The Blender scene drew the tilt servo as an MG996R at the head's centre, the valve at the
pump's z, and both the pump and the valve 41 mm from where the statue measured the legs.

**Dead code out of the mech package and the assembler.** `mech.common`'s `valve_body()` and
`pump_body()`, `turntable.jet_axis()` (which raised a math domain error when called), `base`'s
`NECK_L`, and four unused locals in `assemble.region()`.

to be pushed onto the M22 the filler cap is cut to at one end and an 18 mm spigot at the other.

## Addendum, 2026-09-27: the parting on a sphere and the nod drive

**The parting.** The head nods again, and pans, both about one point C = (0, 0, 350) in the neck.
A rotation about a point keeps every sphere about it, so the statue is parted on one: the fixed
coat inside 98 mm of C, the turning unit - beard, head, hat - outside 100. The coat above the belt
ring is a new piece, the `collar`: a socket closed by a dome with a 55 mm bore, and the bib the
beard lies on. It is fitted after the mechanism, on four tabs down into the ring and four radial
countersunk screws. The glued unit turned out to have no straight way onto the collar - its faces
on the sphere look at C from more than a hemisphere - so the beard is printed in two halves that go
on sideways and screw to the head.

**The nod drive.** A 6810-2RS (50 × 65 × 7) replaces the lazy susan; the plate rides its inner ring
and hangs a yoke down its bore to a Ø4 pin at C. The stem, a 12 mm blade leaning back 5°, turns on
the pin and carries the spider, which carries the unit on the four inserts the neck shroud had.
An MG996R on the yoke's +Y side drives the stem through a round horn let into its hub; printed
stops at −16/+6. The nozzle is fixed in the mouth, 10 mm long because the sphere leaves no room
for more; the tube runs inside the stem and the head's socket slides onto it. The micro servo, the
nozzle arm, the tilt bracket, the shroud and the shaft are gone. `test_pose.py` poses the whole
machine over pan × nod, `test_assembly.py` sweeps the assembly order.

**Firmware follow-up, on another branch:** the tilt limits become −15/+5 (`tiltMin`/`tiltMax` in
`firmware/lib/dwarf/types.h`, now −30/+40, and the protocol fixture's `cfg`), and the tilt
channel's calibration is an MG996R's.
